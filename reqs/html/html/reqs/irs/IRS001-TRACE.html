    • IA-SYS-001
      1. Python package UID: IA-SYS-001 STATUS: Active RELATIONS (Child):
      • IA-IRS-001 Public package imports
      • IA-SDD-001 Source layout
      • IA-SDD-005 Clean Python baseline
      • IA-REQ-001 StrictDoc source of truth
      • IA-TD-001 Package import test
      STATEMENT: The software SHALL be implemented as an installable Python package named ironair.

      All public APIs SHALL be importable using:

      import ironair
      from ironair import constants
      from ironair import chemistry
      from ironair import components
      from ironair import simulation
      from ironair import scenarios
      from ironair import plotting

      The implementation SHALL use a standard src/ package layout.

      The project SHALL provide editable installation using:

      pip install -e ".[dev,notebooks]"
       RATIONALE: A single installable package is the integration boundary for notebooks, tests, and coupled simulation.
      The SDRS src/ layout takes precedence over the generic no-src-directory Cursor rule for this project.
       COMMENT: Package ironair installs in a virtual environment. The listed imports succeed after
      pip install -e ".[dev,notebooks]" or the equivalent uv installation.

    • IA-ODE-001
      19. Common component protocol UID: IA-ODE-001 STATUS: Active RELATIONS (Parent):
      • IA-SYS-003 ODE-based components
      RELATIONS (Child):
      • IA-IRS-002 RHS signature
      • IA-SDD-002 Dynamic component base
      • IA-TD-005 RHS determinism test
      STATEMENT: Every dynamic component SHALL implement rhs(self, t, y, inputs, context).

      The RHS SHALL be deterministic for a fixed state, time, input, and parameter configuration.

      It SHALL NOT modify component state through hidden side effects.
       COMMENT: Repeated rhs evaluations with identical arguments return identical arrays. Component
      parameter objects are unchanged after rhs.
    IA-IRS-002
    2. RHS signature UID: IA-IRS-002 STATUS: Active RELATIONS (Parent):
    • IA-ODE-001 Common component protocol
    STATEMENT: Every dynamic component SHALL expose:

    def rhs(self, t, y, inputs, context) -> numpy.ndarray

    t is time in seconds, y is a 1-D float64 state vector, inputs is a mapping of named
    physical inputs, and context carries shared couplings without hidden mutation of
    component parameters.
     COMMENT: Signature inspection and a deterministic double-evaluation test pass for each component.
    • IA-ODE-003
      21. Coupled solver UID: IA-ODE-003 STATUS: Active RELATIONS (Child):
      • IA-IRS-003 CoupledSystem simulate interface
      STATEMENT: Implement ironair.simulation.CoupledSystem.

      The solver SHALL assemble component states into one global state vector, maintain a
      state-index map, resolve shared inputs and algebraic couplings, evaluate the coupled
      RHS, pass the assembled system to SciPy, detect numerical failures, and return state
      trajectories and diagnostics.
       COMMENT: simulate() returns a SimulationResult with t, y, names, and solver diagnostics.
      Failure of solve_ivp is reported rather than silently truncated.
    IA-IRS-003
    3. CoupledSystem simulate interface UID: IA-IRS-003 STATUS: Active RELATIONS (Parent):
    • IA-ODE-003 Coupled solver
    STATEMENT: ironair.simulation.CoupledSystem.simulate SHALL accept t_span, optional t_eval,
    optional inputs callable, solver method, and tolerances, and SHALL return a
    SimulationResult.
     COMMENT: Default method is BDF or Radau. Result includes t, y, state_names, and diagnostics.

    • IA-EST-001
      30. State estimation UID: IA-EST-001 STATUS: Active RELATIONS (Child):
      • IA-IRS-005 Estimator measurement-only interface
      STATEMENT: Module ironair.controls.estimation SHALL provide class BatteryStateEstimator.

      The model SHALL estimate SOC, SOH, active iron inventory, and available charge/discharge power.

      It SHALL not access the simulated plant's true hidden states during observer execution.
       COMMENT: Estimator rhs and update methods accept only measurements and previous estimates,
      never plant.y hidden components.
    IA-IRS-005
    5. Estimator measurement-only interface UID: IA-IRS-005 STATUS: Active RELATIONS (Parent):
    • IA-EST-001 State estimation
    STATEMENT: BatteryStateEstimator SHALL accept measurements and prior estimates only. It SHALL
    NOT receive the plant hidden state vector during observer execution.
     COMMENT: Type hints and tests pass a MeasurementVector, not the plant y, into the estimator.
