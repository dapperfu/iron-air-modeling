        SEC-IRS-PY
        SEC-IRS-PY
        Python package interfaces
        TEXT
        This Interface Requirements Specification (IRS) covers Python public APIs and the
        physical interfaces of the patented plant that those APIs must expose as named
        inputs, outputs, and couplings: air, electrolyte, electrical tabs, stacking
        contacts, and charge/discharge electrode selection (US12308414B2 and EP4602674A1).
        REQUIREMENT
        		1.1
        IA-IRS-001
        Active

        • IA-SYS-001 Python package
        IA-IRS-001
        Public package imports
        The following imports SHALL succeed after editable install:

        import ironair
        from ironair import constants
        from ironair import chemistry
        from ironair import components
        from ironair import simulation
        from ironair import scenarios
        from ironair import plotting
        tests/test_package_imports.py passes in the project virtual environment.

        Active
        Parents:
        • IA-ODE-001 Common component protocol
        IA-IRS-002
        RHS signature
        Every dynamic component SHALL expose:

        def rhs(self, t, y, inputs, context) -> numpy.ndarray

        t is time in seconds, y is a 1-D float64 state vector, inputs is a mapping of named
        physical inputs, and context carries shared couplings without hidden mutation of
        component parameters.
        Signature inspection and a deterministic double-evaluation test pass for each component.
        REQUIREMENT
        		1.3
        IA-IRS-003
        Active
        Parents:
        • IA-ODE-003 Coupled solver
        IA-IRS-003
        CoupledSystem simulate interface
        ironair.simulation.CoupledSystem.simulate SHALL accept t_span, optional t_eval,
        optional inputs callable, solver method, and tolerances, and SHALL return a
        SimulationResult.

        t_span SHALL accept LODES windows including 8 h, 100 h (3.6e5 s), 300 h, and
        multi-day values from US12308414B2 without changing parameter objects.
        Default method is BDF or Radau. Result includes t, y, state_names, and diagnostics.
        REQUIREMENT
        		1.4
        IA-IRS-004
        Active
        Parents:
        • IA-NBK-003 Shared plotting API
        IA-IRS-004
        Plotting input types
        ironair.plotting functions SHALL accept SimulationResult or pandas.DataFrame.

        Plot metadata SHALL be able to carry scenario identifier, patent source citation,
        and operating assumptions (electrolyte molarity, temperature, architecture mode).
        Both input types produce a matplotlib Figure.
        REQUIREMENT
        		1.5

        Active

        • IA-EST-001 State estimation
        IA-IRS-005
        Estimator measurement-only interface
        BatteryStateEstimator SHALL accept measurements and prior estimates only. It SHALL
        NOT receive the plant hidden state vector during observer execution.
        Type hints and tests pass a MeasurementVector, not the plant y, into the estimator.

        IA-IRS-006
        Active
        Parents:
        • IA-SYS-014 Airflow regulation and ORR separator
        IA-IRS-006
        Air interface
        AirSystem and OxygenReduction SHALL exchange named flows for dry air or oxygen,
        humidity, CO2 mole fraction, pO2, volumetric or mass flow, and manifold pressure.

        ORR SHALL expose an electrolyte-facing first surface and an air-facing second
        surface (EP4602674A1 Claim 1). Stacked submerged ORR sections SHALL expose per-
        section pressure drop so that Claim 1 equal-dP can be enforced.

        Airflow regulation structures including holed ramp arrays (US12308414B2 Claims 14-15)
        SHALL appear as named hydraulic parameters, not as undocumented magic numbers.
        REQUIREMENT
        		2.2
        IA-IRS-007
        Active
        Parents:
        • IA-SYS-021 Electrolyte composition and pH domain
        IA-IRS-007
        Electrolyte and hydraulic interface
        Electrolyte, Reservoir, Pump, Valve, and Pipe SHALL exchange water, KOH/NaOH/LiOH,
        carbonate, dissolved oxygen, liquid volume, temperature, and leak flows.

        Primary-to-secondary containment leak into vessel cavity 161 (US12308414B2
        FIGS. 1E-1F) SHALL be a named leak path. Shared electrolyte baths of multiple
        cells SHALL use a common electrolyte context key.
        REQUIREMENT
        		2.3
        IA-IRS-008
        Active
        Parents:
        • IA-SYS-025 Current collectors, separators, and seals
        IA-IRS-008
        Electrical tab and stacking interface
        Iron, ORR, and OER components SHALL expose named electrical ports for anode tabs,
        OER cathode tabs, ORR tabs, can-negative housing, and stacking contact points
        (US12308414B2 Claims 3 and 5; EP4602674A1 FIG. 8 tabs 230, 240a, 240b).

        Charge and discharge paths SHALL be distinct named connections selectable by
        SupervisoryController. Bus bars outside the active-area plane (EP4602674A1
        Claims 30-31) SHALL be identifiable in the state-index map.
        REQUIREMENT
        		2.4
        IA-IRS-009
        Active
        Parents:
        • IA-SYS-016 Channel and OER projection geometry
        IA-IRS-009
        Channel and interdigitation interface
        IronElectrode SHALL publish channel occupancy, ChanFrac, rib width, and whether
        each channel contains OER, additive, both, or neither (EP4602674A1 Claims 5-6).

        OxygenEvolution SHALL publish projection length, trunk presence, corrugated versus
        discrete-cathode layout, and iron-OER gap. Separator SHALL publish ionic
        resistance and bubble-egress availability between those ports.
        REQUIREMENT
        		2.5

        • IA-SYS-006 Patent-grounded plant of record
        IA-IRS-010
        Scenario and architecture selection interface
        ironair.scenarios SHALL accept an architecture identifier covering US12308414B2
        Claim 1 stacked ORR, Claim 18 DRI bed, floating ORR, and EP4602674A1 Claims 1, 20,
        38, 55, 70, and 77 layouts.

        Invalid combinations (for example bifunctional ORR forced to OER potential while
        isolation is required) SHALL raise a documented configuration error.
