    • IA-SYS-003
      3. ODE-based components UID: IA-SYS-003 STATUS: Active RELATIONS (Child):
      • IA-SDD-004 Algebraic versus dynamic states
      • IA-ODE-001 Common component protocol
      • IA-FE-001 Iron electrode ODE
      STATEMENT: Every physical component SHALL expose a dynamic ODE model.

      Each component SHALL explicitly define: state vector, state units, initial conditions,
      input variables, output variables, governing differential equations, algebraic constitutive
      relations, physical parameters, boundary conditions, conservation residuals, numerical
      constraints, and associated StrictDoc requirement IDs.

      Every component SHALL provide a rhs() method returning state derivatives.

      The generic mathematical representation SHALL be:

      dx/dt = f(t, x, inputs, parameters)

      Where required:

      0 = g(t, x, algebraic_variables, inputs, parameters)

      Algebraic variables SHALL be solved consistently during RHS evaluation or through a
      supported DAE backend.

      An artificial time constant SHALL NOT be introduced solely to make an instantaneous
      physical relation appear dynamic.

      Passive structures, such as current collectors, SHALL possess actual dynamic states
      where justified, such as temperature. Their instantaneous electrical resistance SHALL
      remain an algebraic relation.
       COMMENT: Every DynamicComponent publishes StateSpec metadata and a deterministic rhs(t, y, inputs, context).
      Algebraic electrical resistance is not converted into a fake lag state.
    IA-FE-001
    1. Iron electrode ODE UID: IA-FE-001 STATUS: Active RELATIONS (Parent):
    • IA-SYS-003 ODE-based components
    STATEMENT: Module ironair.components.iron_electrode SHALL provide class IronElectrode.

    The component SHALL dynamically model metallic iron, Fe(OH)2, Fe3O4, active surface
    area, passivation thickness, porosity, electrode temperature, and irreversible
    active-material loss.

    The RHS SHALL calculate iron phase derivatives from the shared reaction network.
     COMMENT: Discharge of Fe increases Fe(OH)2 using IA-CHM-002 stoichiometry. Temperature is a
    dynamic state. Passivation thickness is nonnegative.
    IA-HER-001
    2. Hydrogen evolution ODE UID: IA-HER-001 STATUS: Active STATEMENT: Module ironair.components.hydrogen SHALL provide class HydrogenEvolution.

    States SHALL include hydrogen inventory and applicable interfacial or gas-transfer dynamics.

    The component SHALL couple hydrogen generation to charging current and electrode potential.
     COMMENT: H2 inventory increases under negative iron overpotential. Open-circuit HER is smaller
    than strong cathodic charging HER.
    IA-ORR-001
    3. Oxygen reduction ODE UID: IA-ORR-001 STATUS: Active STATEMENT: Module ironair.components.oxygen_reduction SHALL provide class OxygenReduction.

    States SHALL include interfacial charge storage and oxygen availability where applicable.

    The component SHALL calculate nonlinear ORR kinetics and oxygen consumption.
     COMMENT: ORR current is negative (cathodic) for eta < 0 versus the ORR Nernst potential.
    Oxygen consumption matches Faraday's law for four-electron ORR.
    IA-OER-001
    4. Oxygen evolution ODE UID: IA-OER-001 STATUS: Active STATEMENT: Module ironair.components.oxygen_evolution SHALL provide class OxygenEvolution.

    The component SHALL calculate oxygen evolution, catalyst activity, and applicable
    dynamic electrode states.
     COMMENT: OER current is positive (anodic) for eta > 0 versus the OER Nernst potential.
    IA-GDL-001
    5. Gas diffusion ODE UID: IA-GDL-001 STATUS: Active STATEMENT: Module ironair.components.gas_diffusion SHALL provide class GasDiffusionLayer.

    The component SHALL calculate transient oxygen concentration profiles, effective
    diffusion, pore saturation, flooding, and gas/liquid transport.
     COMMENT: A step decrease in boundary O2 mole fraction produces a delayed interior O2 decline.
    Flooding (saturation -> 1) reduces effective O2 diffusivity.
    IA-ELY-001
    6. Electrolyte ODE UID: IA-ELY-001 STATUS: Active STATEMENT: Module ironair.components.electrolyte SHALL provide class Electrolyte.

    States SHALL include water inventory, dissolved species, electrolyte temperature,
    carbonation, and spatial concentration distributions where enabled.

    The model SHALL include concentration-dependent KOH physical properties.
     COMMENT: Conductivity is computed from instantaneous KOH concentration and temperature via
    ironair.properties. Carbonate accumulation consumes OH-.
    IA-SEP-001
    7. Separator ODE UID: IA-SEP-001 STATUS: Active STATEMENT: Module ironair.components.separator SHALL provide class Separator.

    The model SHALL represent transient species transport, electrolyte saturation where
    applicable, degradation, and separator temperature.

    Ionic resistance SHALL be calculated from the instantaneous physical state.
     COMMENT: R_ionic is algebraic in conductivity, thickness, area, and saturation. Temperature
    is dynamic.
    IA-COL-001
    8. Current collector ODE UID: IA-COL-001 STATUS: Active STATEMENT: Module ironair.components.current_collector SHALL provide class CurrentCollector.

    The model SHALL include thermal dynamics and configurable long-term contact or
    resistance degradation.

    Ohmic voltage loss SHALL be calculated algebraically.
     COMMENT: No fake lag state for resistance. V_ohm = I * R(T, degradation_state).
    IA-CEL-001
    9. Complete cell ODE UID: IA-CEL-001 STATUS: Active STATEMENT: Module ironair.components.cell SHALL provide class IronAirCell.

    The cell SHALL couple iron electrode, air electrode, hydrogen evolution, electrolyte,
    separator, gas diffusion, current collectors, and thermal dynamics.

    The cell SHALL calculate instantaneous terminal voltage, current, power, SOC, and
    available capacity.

    The component SHALL solve coupled nonlinear electrochemical and electrical constraints.
     COMMENT: Cell rhs solves algebraic current/voltage consistency. Outputs include V, I, P, SOC.
    IA-THM-001
    10. Thermal ODE UID: IA-THM-001 STATUS: Active STATEMENT: Module ironair.components.thermal SHALL provide class ThermalNetwork.

    States SHALL include thermal energy or temperature at relevant physical nodes.

    The model SHALL calculate conduction, convection, radiation, reaction heat, and cooling.
     COMMENT: Adiabatic isolated node with positive heat source increases temperature.
    IA-AIR-001
    11. Air handling ODE UID: IA-AIR-001 STATUS: Active STATEMENT: Module ironair.components.air_system SHALL provide class AirSystem.

    The component SHALL include gas inventories, manifold pressure dynamics, oxygen
    concentration, humidity, and airflow coupling.
     COMMENT: Manifold pressure rises when inlet mass flow exceeds outlet plus consumption.
    IA-AIR-002
    12. Fan ODE UID: IA-AIR-002 STATUS: Active STATEMENT: Module ironair.components.fan SHALL provide class Fan.

    The model SHALL include rotor speed dynamics and fan power consumption.
     COMMENT: Rotor speed is a dynamic state. Electrical power is an algebraic output from speed and torque.
    IA-FLD-001
    13. Electrolyte circulation ODE UID: IA-FLD-001 STATUS: Active STATEMENT: Module ironair.components.electrolyte_flow SHALL provide class ElectrolyteFlow.

    The component SHALL dynamically track flow, species transfer, pressure or hydraulic
    storage where physically justified, and temperature.
     COMMENT: Species transport delay appears when using the detailed hydraulic mode.
    IA-FLD-002
    14. Pump ODE UID: IA-FLD-002 STATUS: Active STATEMENT: Module ironair.components.pump SHALL provide class Pump.

    The component SHALL model motor and hydraulic response, electrical input, and mechanical losses.
     COMMENT: Shaft speed is dynamic. Hydraulic power is less than electrical input by documented efficiency.
    IA-FLD-003
    15. Reservoir ODE UID: IA-FLD-003 STATUS: Active STATEMENT: Module ironair.components.reservoir SHALL provide class Reservoir.

    The component SHALL model liquid inventory, chemical species inventories, temperature,
    and boundary flows.
     COMMENT: Mass balance: dM/dt equals inlet minus outlet minus leak.
    IA-FLD-004
    16. Valve ODE UID: IA-FLD-004 STATUS: Active STATEMENT: Module ironair.components.valve SHALL provide class Valve.

    The component SHALL model actuator response, valve position, and flow-dependent
    hydraulic characteristics.
     COMMENT: Position is a dynamic actuator state. Flow is algebraic in position and pressure drop.
    IA-FLD-005
    17. Piping ODE UID: IA-FLD-005 STATUS: Active STATEMENT: Module ironair.components.piping SHALL provide class Pipe.

    The component SHALL model transient fluid transport and temperature or species
    residence-time dynamics when using the detailed hydraulic mode.
     COMMENT: Detailed mode has at least one transport delay state. Lumped mode is flagged reduced_order.
    IA-HEX-001
    18. Heat exchanger ODE UID: IA-HEX-001 STATUS: Active STATEMENT: Module ironair.components.heat_exchanger SHALL provide class HeatExchanger.

    The component SHALL represent thermal storage and dynamic heat transfer between fluid circuits.
     COMMENT: Two fluid temperatures approach each other under heat transfer with no external loss.
    IA-STK-001
    19. Stack ODE UID: IA-STK-001 STATUS: Active STATEMENT: Module ironair.components.stack SHALL provide class BatteryStack.

    The component SHALL aggregate cell states while preserving cell-level variations and
    electrical current conservation.
     COMMENT: Series stack current is identical through cells. Terminal voltage is the sum of cell voltages.
    IA-MOD-001
    20. Module ODE UID: IA-MOD-001 STATUS: Active STATEMENT: Module ironair.components.module SHALL provide class BatteryModule.

    The model SHALL include coupled stacks, shared fluid equipment, air equipment, and thermal states.
     COMMENT: Module assembles at least one stack plus shared thermal or fluid nodes.
    IA-ENC-001
    21. Enclosure ODE UID: IA-ENC-001 STATUS: Active STATEMENT: Module ironair.components.enclosure SHALL provide class BatteryEnclosure.

    The model SHALL include enclosure temperature, ventilation, auxiliary electrical loads,
    and enclosure-level gas inventories.
     COMMENT: Ventilation flow reduces enclosure H2 inventory. Auxiliary load is an algebraic electrical output.
    IA-DC-001
    22. DC bus ODE UID: IA-DC-001 STATUS: Active STATEMENT: Module ironair.components.dc_bus SHALL provide class DCBus.

    The component SHALL model DC link capacitor voltage and stored energy.
     COMMENT: C * V * dV/dt equals net electrical power into the capacitor.
    IA-CNV-001
    23. DC/DC converter ODE UID: IA-CNV-001 STATUS: Active STATEMENT: Module ironair.components.dc_converter SHALL provide class DCDCConverter.

    The model SHALL include averaged inductor current, capacitor voltage, and converter losses.
     COMMENT: Averaged inductor current is a dynamic state. Losses increase output current demand.
    IA-INV-001
    24. Inverter ODE UID: IA-INV-001 STATUS: Active STATEMENT: Module ironair.components.inverter SHALL provide class GridInverter.

    The model SHALL include averaged electrical control dynamics, DC link interaction,
    and active/reactive power response.
     COMMENT: P and Q track references through explicit controller states, not prescribed algebraic jumps only.
    IA-TRF-001
    25. Transformer ODE UID: IA-TRF-001 STATUS: Active STATEMENT: Module ironair.components.transformer SHALL provide class Transformer.

    The component SHALL include electromagnetic dynamic states where detailed transient
    modeling is enabled, along with winding and core thermal dynamics.
     COMMENT: Detailed mode includes flux or current states. Thermal states exist in both modes.
    Prescribed grid voltage is an input, not a transformer state.
    IA-GRD-001
    26. Grid interface ODE UID: IA-GRD-001 STATUS: Active STATEMENT: Module ironair.components.grid SHALL provide class GridInterface.

    The grid SHALL support dynamic voltage and frequency disturbances, network interface
    equations, and configurable external-grid dynamic models.

    A prescribed grid voltage or frequency SHALL be treated as an external input, not an
    invented dynamic state.
     COMMENT: When voltage/frequency are prescribed, they appear in inputs. Optional swing-equation
    mode is explicitly identified.
    IA-DEG-001
    27. Degradation ODE UID: IA-DEG-001 STATUS: Active STATEMENT: Module ironair.components.degradation SHALL provide class Degradation.

    The model SHALL represent irreversible material changes, catalyst decay, resistance
    growth, and active capacity loss.
     COMMENT: Degradation states are nondecreasing under positive aging rates. Capacity loss is irreversible.
    IA-FLT-001
    28. Sensor ODE UID: IA-FLT-001 STATUS: Active STATEMENT: Module ironair.components.sensors SHALL provide class DynamicSensor.

    The model SHALL include finite response time, sensor drift, bias, and noise.
     COMMENT: First-order sensor lag is a dynamic state. Noise uses a documented random seed.
    IA-CTL-001
    29. Supervisory control dynamics UID: IA-CTL-001 STATUS: Active STATEMENT: Module ironair.controls.supervisory SHALL provide class SupervisoryController.

    The controller SHALL include explicit continuous controller states where applicable,
    as well as discrete operating modes.

    It SHALL be implemented as a hybrid system with ODE dynamics and discrete transitions.
     COMMENT: Mode transitions are event-driven. PI or equivalent continuous states exist for current/power regulation.
