    1. Requirements management

     UID: SEC-SSS1-REQ
    This document specifies foundation, chemistry, ODE, notebook, and verification
    requirements for ironair. Chemical stoichiometry, capacities, electrolyte
    compositions, and kinetics domains are taken from US12308414B2 and EP4602674A1.
    Software tests verify implementation against these statements; they do not
    validate the patents experimentally.
    • IA-SYS-001
      1.1. Python package UID: IA-SYS-001 STATUS: Active RELATIONS (Child):
      • IA-IRS-001 Public package imports
      • IA-SDD-001 Source layout
      • IA-SDD-005 Clean Python baseline
      • IA-REQ-001 StrictDoc source of truth
      • IA-TD-001 Package import test
      STATEMENT: The software SHALL be implemented as an installable Python package named ironair.

      All public APIs SHALL be importable using:

      import ironair
      from ironair import constants
      from ironair import chemistry
      from ironair import components
      from ironair import simulation
      from ironair import scenarios
      from ironair import plotting

      The implementation SHALL use a standard src/ package layout.

      The project SHALL provide editable installation using:

      pip install -e ".[dev,notebooks]"
       RATIONALE: A single installable package is the integration boundary for notebooks, tests, and
      coupled simulation of the patented iron-air plant. The SDRS src/ layout takes
      precedence over the generic no-src-directory Cursor rule for this project.
       COMMENT: Package ironair installs in a virtual environment. The listed imports succeed after
      pip install -e ".[dev,notebooks]" or the equivalent uv installation.

    SEC-SSS1-CON

    2. Constants, parameters, and property models

     UID: SEC-SSS1-CON
    US12308414B2 defines room temperature as 25 C and standard temperature and
    pressure as 25 C and 1 atm, with "about" meaning plus or minus 10 percent or
    instrument error, whichever is larger. EP4602674A1 simulations use 6 M KOH at
    303 K. Property models SHALL cover those reference states.

    STATEMENT: Implement src/ironair/constants.py providing F_C_MOL, R_J_MOL_K, T_REF_K, P_REF_PA,
    M_FE_KG_MOL, M_O2_KG_MOL, M_H2O_KG_MOL, and M_KOH_KG_MOL.

    Fundamental constants SHALL be immutable.

    within documented precision. Assignment to module constants raises an error or is
    rejected by typing/runtime freeze.

    IA-CON-002
    2.2. Parameter definitions UID: IA-CON-002 STATUS: Active STATEMENT: Every component SHALL use explicit, typed parameter objects.

    Parameters SHALL include name, value, SI unit, physical meaning, valid range,
    source classification, literature reference when available, uncertainty when available,
    and calibration status.

    Parameter categories SHALL distinguish fundamental constant, literature value,
    experimental measurement, engineering design assumption, calibrated coefficient,
    and unverified placeholder.

    Patent-disclosed values (electrolyte molarity, channel lengths, iron loading,
    pO2 windows, theoretical mAh/g) SHALL be tagged as literature value with the
    patent number and claim or paragraph in the literature-reference field. They
    SHALL NOT be tagged as experimental measurement unless an independent hardware
    campaign is recorded.
     COMMENT: PhysicalParameter dataclass enforces required fields and rejects out-of-range values.
    Unverified placeholders are queryable via calibration_status.
    • IA-SYS-021
      5.2. Electrolyte composition and pH domain UID: IA-SYS-021 STATUS: Active RELATIONS (Parent):
      • IA-SYS-002 Integrated physics simulation
      RELATIONS (Child):
      • IA-IRS-007 Electrolyte and hydraulic interface
      • IA-CON-003 Property models
      • IA-ELY-001 Electrolyte ODE
      • IA-TD-010 Electrolyte and loading domain test
      STATEMENT: The default liquid electrolyte SHALL be an aqueous alkaline hydroxide solution.

      The model SHALL accept compositions disclosed in the patents, including:

      - 6 M KOH (US12308414B2; EP4602674A1 simulation electrolyte at 303 K);
      - 5.5 M KOH + 0.5 M LiOH;
      - 6 M NaOH;
      - 5 M NaOH + 1 M KOH;
      - about 4 M KOH + 2 M NaOH + 0.05 M LiOH, or 4 M NaOH + 2 M KOH + 0.05 M LiOH;
      - high hydroxide at or above 5 M, including 5-6 M, 6-7 M, 7-11 M, 7-10 M,
      7.5-9.5 M, and 7 M or greater (EP4602674A1 electrolyte section).

      pH SHALL be modelable as acidic (pH < 4), near-neutral (4 < pH < 10), or alkaline
      (pH > 10), with alkaline pH greater than 10 or greater than 12 as preferred
      operating points (US12308414B2 electrolyte paragraph).

      Electrolyte type MAY also be solid oxide, solid polymer, molten salt, non-aqueous,
      gel, or combinations (EP4602674A1 Claims 14-15), but aqueous alkali hydroxide is
      the verified modeling default.
       RATIONALE: US12308414B2 liquid electrolyte examples; EP4602674A1 Claims 14-15 and [0231]-[0241].
      High hydroxide is disclosed to increase capacity, improve coulombic efficiency, and
      decrease overpotential.

      STATEMENT: The software SHALL model the complete iron-air battery as a coupled multiphysics
      system corresponding to the patented plant.

      The model SHALL include metallic iron electrode, iron hydroxide and oxide phases,
      oxygen reduction electrode, oxygen evolution electrode, hydrogen evolution,
      alkaline electrolyte, electrolyte transport, separator, gas diffusion layer,
      current collectors, cell assembly, thermal system, air intake, fan/blower, gas
      manifolds, ventilation, electrolyte reservoir, circulation pump, piping, valves,
      heat exchanger, battery stack, battery module, battery enclosure, DC electrical
      distribution, DC/DC conversion, grid inverter, transformer, grid interface,
      measurement sensors, battery management, supervisory control, fault management,
      state estimation, and degradation and aging.

      These components SHALL interact through shared physical quantities and conserved
      material, charge, and energy flows.

      Vessel, lid, and air-delivery functions disclosed in US12308414B2 (electrolyte
      containment, secondary containment, thermal management cavity, air distribution,
      process-gas venting, current collection, sensing, DC connections) SHALL map onto
      the enclosure, air-system, thermal, collector, and control components listed
      above.
       RATIONALE: Balance-of-plant and grid interfaces determine operating envelopes of the
      electrochemical cell. US12308414B2 FIGS. 1E-1F, 9A, and 94-102 describe
      multi-function vessels, lids, and bulk energy storage systems. EP4602674A1 FIG. 1
      adds the dual-electrode switch between power source (charge) and load (discharge).
       COMMENT: Every listed component has a DynamicComponent implementation that can be assembled
      into ironair.simulation.CoupledSystem and exchanges named physical flows.
    IA-CHM-001
    3.1. Stoichiometric reaction network UID: IA-CHM-001 STATUS: Active RELATIONS (Parent):
    • IA-SYS-002 Integrated physics simulation
    STATEMENT: Implement a common chemical reaction network.

    Mathematical model:

    dn/dt = S @ r + B @ q

    Where S is the chemical stoichiometric matrix, r is the reaction-rate vector,
    B maps boundary flows to species inventories, and q is the boundary-flow vector.

    The reaction network SHALL enforce elemental conservation.
     COMMENT: For every reaction column, elemental composition @ S[:, j] is numerically zero.

      5.1. Iron-air reaction set UID: IA-SYS-020 STATUS: Active RELATIONS (Parent):

      - Fe + 2OH- <-> Fe(OH)2 + 2e- with 960 mAh/g-Fe theoretical first-step capacity
      (EP4602674A1 [0042]-[0043] Equation 1);
      - subsequent oxidation of iron hydroxide to magnetite Fe3O4 with 320 mAh/g-Fe
      theoretical second-step capacity (Equation 2);
      - ORR O2 + 2H2O + 4e- -> 4OH- (US12308414B2 detailed description);
      - OER 4OH- -> O2 + 2H2O + 4e- as the independent reverse oxygen couple;
      - HER 2H2O + 2e- -> H2 + 2OH- as the parasitic charge side reaction
      (EP4602674A1 [0044], [0047]).

      Discharge volume increase SHALL be taken up in anode porosity rather than by
      inventing extra inventory.
       RATIONALE: EP4602674A1 [0042]-[0047]; US12308414B2 air-electrode half-reaction and triple-phase
      boundary discussion. Interdigitated OER reduces ionic path length so charge current
      is less likely to divert to HER at the electrode front ([0050], FIGS. 19-21).

    4. ODE protocol, solvers, and multiscale execution

     UID: SEC-SSS1-ODE

      7.1. ODE-based components UID: IA-SYS-003 STATUS: Active RELATIONS (Child):
      • IA-SDD-004 Algebraic versus dynamic states
      • IA-ODE-001 Common component protocol
      • IA-FE-001 Iron electrode ODE
      STATEMENT: Every physical component SHALL expose a dynamic ODE model.

      Each component SHALL explicitly define: state vector, state units, initial
      conditions, input variables, output variables, governing differential equations,
      algebraic constitutive relations, physical parameters, boundary conditions,
      conservation residuals, numerical constraints, and associated StrictDoc
      requirement IDs.

      Every component SHALL provide a rhs() method returning state derivatives.

      The generic mathematical representation SHALL be:

      dx/dt = f(t, x, inputs, parameters)

      Where required:

      0 = g(t, x, algebraic_variables, inputs, parameters)

      Algebraic variables SHALL be solved consistently during RHS evaluation or through
      a supported DAE backend.

      An artificial time constant SHALL NOT be introduced solely to make an instantaneous
      physical relation appear dynamic.

      Passive structures, such as current collectors, SHALL possess actual dynamic states
      where justified, such as temperature. Their instantaneous electrical resistance
      SHALL remain an algebraic relation.

      Patent-derived algebraic laws SHALL include Ohmic drop, hydraulic orifice and
      equalized stacked-ORR pressure drop, Nernst potential, and Faraday mapping of
      current to reaction rate.
       COMMENT: Every DynamicComponent publishes StateSpec metadata and a deterministic
      rhs(t, y, inputs, context). Algebraic electrical resistance is not converted into
      a fake lag state.
