        Source layout
        Package sources SHALL live under src/ironair as specified by IA-SYS-001.

        This SDRS src/ layout is the project-specific design and SHALL be used even though
        a generic Cursor rule discourages src/ layouts.
        pyproject.toml configures setuptools package discovery with where = ["src"].

        IA-SDD-002
        Dynamic component base
        All physical components SHALL implement ironair.ode.protocol.DynamicComponentProtocol
        and MAY inherit ironair.ode.component.DynamicComponent for shared validation.

        rhs(t, y, inputs, context) SHALL be a pure function of its arguments for a fixed
        parameter configuration.
        Protocol checks and unit tests cover every registered component class.

        IA-SDD-003
        Shared chemistry ownership
        Electrode components SHALL obtain stoichiometric rates from ironair.chemistry rather
        than embedding a second reaction network.
        Iron, ORR, OER, and HER rate mapping uses ReactionNetwork.S and Faraday conversion.

        • IA-SYS-003 ODE-based components
        IA-SDD-004
        Algebraic versus dynamic states
        Instantaneous constitutive laws (Ohmic drop, hydraulic orifice flow at a fixed
        position, Nernst potential) SHALL be algebraic.

        Dynamic states SHALL represent stored mass, charge, thermal energy, momentum, or
        explicit controller memory.

        Artificial lag SHALL NOT be added to algebraic laws.
        CurrentCollector resistance is algebraic. CurrentCollector temperature is dynamic.

        • IA-SYS-001 Python package
        IA-SDD-005
        Clean Python baseline
        This Python package is a new baseline. It SHALL NOT import, translate, or recover
        governing equations from prior MATLAB or Simulink implementations.
        Source tree contains no .m or .slx physics. Chemistry and component modules implement
        the SDRS reaction set and ODE protocol directly.
