# Physics

The canonical stoichiometric network in `core/ironair_reaction_network.m` is the only source of reaction-driven species derivatives.

Tracked reactions: Fe/FeOH2, optional magnetite, ORR, OER, HER, and carbonation.

Internal units: kelvin, pascal, mol/m3, ampere, watt, joule.

Discharge-positive current: `I_cell > 0` delivers electrical power from the cell.
